# Broadcast Business suite

A professional broadcast control application for **Virtual** **Drift** events.

## Features

### Current

* React + TypeScript
* OBS WebSocket Connection
* Dashboard
* Professional UI

### Planned

#### Broadcast

* VS Overlay
* Winner Overlay
* Lower Third
* Judge Scores
* Sponsor Graphics

#### Drivers

* Driver Database
* Team Database
* Car Database
* Driver Photos

#### Tournament

* Top 32
* Top 16
* Great 8
* Final Four
* Finals
* Championship Standings

#### OBS

* Scene Control
* Source Visibility
* Browser Source Control
* Recording
* Streaming

#### Assetto Corsa

* Live Driver Detection
* Battle Detection
* Track Detection
* Automatic Overlay Updates

## Tech Stack

* React
